# hanmask

[English](README.md) | 繁體中文

自架的 LLM 代理服務：個資在離開公司網路前先被遮蔽，模型回答回來時再自動還原。針對繁體中文與台灣常見個資格式設計。

## 為什麼需要

企業想用雲端 LLM，但客戶姓名、電話、身分證字號不能送出去，結果多半是全面禁用，或員工私下使用。hanmask 放在你的程式和 LLM API 之間：

1. 程式照常呼叫 API，只要把 `base_url` 指向 hanmask。
2. 個資被換成 `<PHONE_1>`、`<TW_ID_1>` 這類佔位符後才送出。
3. 回答回來時，佔位符換回原文，使用者感覺不到中間有一層。
4. 對照表只存在記憶體裡，請求結束就丟棄；稽核日誌只記類型與數量，不存原文。

## 目前支援的個資類型

| 類型 | 佔位符 | 說明 |
|---|---|---|
| 身分證字號、居留證號 | `<TW_ID_n>` | 含檢查碼驗證；支援新式（A800000014）與舊式（AB12345677）居留證 |
| 統一編號 | `<TW_UBN_n>` | 含檢查碼驗證（財政部 2023 年後規則） |
| 手機、市話 | `<PHONE_n>` | `0912-345-678`、`+886 912 345 678`、`(02)2345-6789` 等格式 |
| Email | `<EMAIL_n>` | |
| 信用卡號 | `<CREDIT_CARD_n>` | Luhn 檢查碼驗證 |
| 護照號碼 | `<PASSPORT_n>` | 前面要有「護照」或 passport |
| 健保卡號 | `<TW_NHI_n>` | 12 位數字，前面要有「健保」 |
| 銀行帳號 | `<BANK_ACCOUNT_n>` | 10–16 位數字，前面要有「帳號」、「匯款」、「轉帳」等關鍵字 |
| 地址 | `<ADDRESS_n>` | 縣市或鄉鎮區＋路街＋門牌號，含郵遞區號、段、巷、弄、樓 |
| 生日 | `<BIRTH_DATE_n>` | 前面要有「生日」、「出生日期」；支援西元與民國 |
| 薪資 | `<SALARY_n>` | 前面要有「月薪」、「年薪」、「獎金」等；其他金額不遮 |
| IP 位址 | `<IP_ADDRESS_n>` | IPv4；前面有「版本」、version 時不遮 |
| UUID | `<UUID_n>` | 裝置 ID、使用者 ID |
| 社群帳號 | `<SOCIAL_ID_n>` | `LINE ID：`、`IG:`、Telegram、微信；只寫「LINE」不算 |

繁體中文的書寫習慣也一併處理：

- **全形字元**：`０９１２－３４５－６７８`、`Ａ１２３４５６７８９`、`（０２）` 都辨識得到，還原時保留原本的全形寫法。
- **中文緊貼數字**：`統編04595257`、`身分證A123456789` 這種前後沒有空白的寫法也抓得到。
- **檢查碼把關**：訂單編號、料號等剛好長得像身分證或統編的字串，檢查碼不符就不遮蔽，減少誤判。
- **關鍵字把關**：看號碼前 20 個字內、同一個子句裡的關鍵字，依序判斷：
  1. 有正向關鍵字（`統編`、`電話`、`身分證`）→ 遮蔽
  2. 護照、健保卡、銀行帳號沒有檢查碼，沒有正向關鍵字就不遮
  3. 有企業識別碼標籤（`訂單`、`單號`、`料號`、`發票`）→ 不當成個資，改由下方的企業識別碼類型處理
  4. 都沒有 → 由格式與檢查碼決定

## 企業識別碼（預設遮蔽）

標籤緊接在值前面才遮蔽，值至少 5 個字元且含數字，例如 `訂單編號：PO-2024-00123`、`發票號碼 AB12345678`。

| 類型 | 佔位符 | 標籤 |
|---|---|---|
| 訂單、單據 | `<ORDER_NO_n>` | 訂單、採購單、出貨單、報價單、單號、Order No. |
| 發票 | `<INVOICE_NO_n>` | 發票、invoice |
| 料號 | `<PART_NO_n>` | 料號、品號、SKU、part |
| 其他編號 | `<REF_NO_n>` | 編號、序號、流水號、案號、批號、代碼、合約、證號、字號（不含「統一編號」） |
| 公司名稱 | `<ORG_NAME_n>` | 以股份有限公司、有限公司、企業社、商行、工作室、事務所、Co., Ltd.、Inc. 結尾 |

只遮個資、不遮企業識別碼：

```python
from hanmask import PII_TYPES, Masker

masker = Masker(enabled=PII_TYPES)
```

## 特種個資（嚴格模式擋下）

病歷、醫療、健康檢查、基因、性生活、犯罪前科（《個資法》第 6 條）是自由文字，無法可靠遮蔽。嚴格模式偵測到相關關鍵字時直接擋下，錯誤只帶類別名稱，不帶原文：

```python
from hanmask import Masker, SensitiveContentError

try:
    Masker(strict=True).mask("請假原因：憂鬱症回診")
except SensitiveContentError as e:
    e.categories  # ["MEDICAL"]
```

中文姓名與沒有法定後綴的公司名稱辨識開發中（本地 NER 模型）。

## 使用範例

```python
from hanmask import Masker, restore

masked, vault = Masker().mask("請聯絡 0912-345-678，身分證 A123456789")
# masked == "請聯絡 <PHONE_1>，身分證 <TW_ID_1>"
restore(masked, vault)  # 還原成原文
```

## 免責聲明

hanmask 協助降低個資外洩風險，但不保證辨識率 100%，也不代表使用後即符合《個人資料保護法》等法規要求。
